# LokalBot autocomplete launch film — "Since May"

A 62.6-second film for the r/LocalLLaMA autocomplete post (the draft stays local; `Docs/reddit-*.md` is gitignored). The render, poster and SRT land in `renders/` (gitignored, like the voice and music stems); captions are also burned in.

First person, warm, one morning, a few notes: a thank-you, an update to the team that autocomplete finishes from yesterday's meeting, four messages in German, French, Italian and Spanish shown together, and a greeting where it stays quiet. It closes with the credit to Cotabby and "tell me where it's wrong."

## What is real

- Every suggestion on screen is real output from LokalBot's autocomplete (Gemma 4 E2B base Q6_K, in-process llama.cpp), typed live in TextEdit on 2026-10-13. Typing and Tab presses were driven by computer use; nothing in the product UI was redrawn. The quiet scene plays at 1.25×.
- The four language rows were typed one after another and are shown together. The Spanish row skips 4.8 s in which nothing on screen changed (the ghost waited for the next Tab). The Italian line needed a fresh document: with the old document's suggested English title in the prompt, the model stayed quiet. The language shoot used the new-install language setting (auto) rather than the author's own hint.
- The filming copy was master `92d87af` with one change: the ghost panel's `sharingType` set to `.readOnly` so screen recording can see it (`filming/build_filming_app.sh`). It ran on a fictional library (`filming/seed_library.py`: "Harbor beta check-in" with Mila) with clipboard, screen memory and learning off.
- "8,176" is the user's own Cotypist count (single-word accepts in its `completionStats.json`, May 28 – Oct 5, 2026).
- The narration is synthetic: Breeze TTS 2 Q8_0 through audio.cpp v0.7.3 on Metal, using the approved male reference from the September film. Breeze's license asks for a written license for commercial use of its output.
- The piano bed is generated by `compose_bed.py` (numpy/scipy, no samples).

## Rebuild

```sh
RAW_DIR=<folder with the raw .mov takes> bash filming/crop_takes.sh   # only if re-cropping
python3 mix_audio.py
python3 build.py
npx --yes hyperframes@0.8.150 check
npx --yes hyperframes@0.8.150 render --fps 30 --quality delivery --workers 4 --strict --output renders/lokalbot-autocomplete-launch.mp4
```

Narration changes: edit `narration.json`, run `generate_breeze.py --runtime <dir>` (needs `breeze-tts-2-q8_0.gguf` and `runtime/audiocpp_server`), pick takes in `production/voice-plan.json`, refresh `word_timings.py`, then adjust caption offsets in `edit.json`. The raw full-display recordings are not in the repository: they show the whole screen.

## Checks run

`hyperframes check` passed (lint, runtime, layout, motion, 19/19 WCAG AA text checks; one accepted warning about caption density). The render is H.264 1920×1080 at 30 fps with AAC 48 kHz stereo, 62.6 s, −15.8 LUFS integrated and −1.5 dBTP. Frames were inspected from the rendered file at 15 points. Each narration take was checked with faster-whisper base.en.
